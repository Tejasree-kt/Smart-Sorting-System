# SMART SORTING : TRANSFER LEARNING FOR IDENTIFYING ROTTEN FRUITS AND VEGETABLES

An automated, AI-powered computer vision pipeline designed to identify and classify the quality of fruits and vegetables in real-time. This system aims to replace traditional manual sorting methods, improving operational efficiency and accuracy in agricultural processing.

## 📌 Project Overview
Manual sorting of fruits and vegetables is time-consuming, labor-intensive, and prone to human error. The **Smart Sorting System** integrates deep learning, computer vision, and transfer learning models to accurately detect subtle visual anomalies such as color degradation, texture spoilage, and tissue rot on conveyor belts or storage systems.

By using transfer learning, pre-trained deep learning models are adapted to deliver high classification accuracy even with limited datasets, significantly reducing training time.

## 🚀 Key Features
* **Real-time Anomaly Detection:** Instantly flags defective items under variable lighting conditions.
* **Noise Reduction Pipeline:** Preprocessed datasets utilizing Pandas and NumPy to reduce background irregularities by 25%.
* **High Efficiency Optimization:** Speeds up sorting lines while maintaining a consistent quality metric.
